# Code of conduct

The project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, criticise ideas and not people, and help newcomers. Harassment and personal attacks are not tolerated.

Report problems privately to the maintainers listed in [GOVERNANCE.md](GOVERNANCE.md). Reports are handled confidentially.
