Complete this scorecard alone, within 24 hours, before you read anyone else's scores or join the debrief. Write evidence: what the candidate said or did. Do not write impressions such as "seemed smart" or "good fit".

## Scale

| Score | Meaning |
|---|---|
| 1 | No evidence, or evidence against |
| 2 | Some evidence, below the level for this role |
| 3 | Clear evidence at the level for this role |
| 4 | Strong evidence above the level for this role |

## Scoring guide examples

Write anchors for each competency before interviews start. Example for "Verification":

- 1: Accepts generated or copied code without reading it. Cannot explain parts of the solution.
- 2: Reads the code but tests only the happy path.
- 3: Tests edge cases, explains every line, notices at least one problem in generated output.
- 4: Designs tests first, finds subtle defects, explains how the code would fail in production.
