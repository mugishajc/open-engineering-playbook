## 1. The plan (5 minutes)

What we intend to do, by when, and what success looks like in 12 months.

- Decision: [...]
- Success measure: [...]

## 2. Imagine failure (10 minutes, silent, alone)

Prompt to read aloud: "It is [date 12 months from now]. This decision has failed badly. Write down every reason why it failed."

Each person writes their own list before anyone speaks.

## 3. Collect reasons (15 minutes)

Go round the room, one reason per person per round, until lists are empty. Record every reason without debate.

| # | Reason it failed | Raised by (optional) |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |

## 4. Group and rank (10 minutes)

Group similar reasons. Each participant gets 3 votes for the most likely or most damaging.

| Theme | Reasons included | Votes |
|---|---|---|
| | | |

## 5. Respond (15 minutes)

For the top 3 to 5 themes, choose one response each.

| Theme | Response (change plan / early warning sign / accept risk) | Action or signal | Owner | Date or review point |
|---|---|---|---|---|
| | | | | |

- [ ] Plan changed: [summary]

- [ ] Accepted risks added to the risk register: [IDs]
- [ ] Results linked from the decision record
- Decision: [proceed / proceed with changes / stop / gather more evidence by date]
