How to use:
1. Agree the criteria and weights BEFORE anyone scores the options. Weights add up to 100.
2. Pick a baseline: the current design or the simplest option. It scores 0 on every row.
3. Score each other option against the baseline: -2 much worse, -1 worse, 0 same, +1 better, +2 much better.
4. Weighted score = weight x score. Add each column.
5. Treat totals within 20 points of each other as a tie (a starting point). Settle ties on
   reversibility, then on what the team can run.
6. Record sensitivity points and trade-off points, then write the decision record.
