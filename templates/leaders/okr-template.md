## Check before publishing

- [ ] No more than 3 objectives.
- [ ] Every key result has a number, a baseline and a data source.
- [ ] No key result is a task ("launch", "migrate", "run training"). Each one describes a change in an outcome.
- [ ] Each objective links to a strategy action.
- [ ] The team helped write these; they were not only handed down.
