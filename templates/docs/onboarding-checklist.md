Copy this file for each new engineer. Tick items as they happen. The new engineer fixes anything in this checklist or the linked docs that turned out wrong.

## Before day one (manager)

- [ ] Accounts requested from the role template when the offer was signed: identity provider, git host, CI, chat, docs, ticketing
- [ ] Laptop ordered, imaged and tested
- [ ] Buddy named and told
- [ ] First-week calendar sent: team meetings, 1:1s, buddy sessions
- [ ] 3 "good first issue" tickets chosen and labelled
- [ ] Assured: screening and contract steps your policy requires are complete and recorded

## Day one

- [ ] Meet manager and buddy
- [ ] Sign in to every system on the account list
- [ ] Clone the main repository, build it and run the tests (target: under 1 hour)
- [ ] Read the team README, the Open Engineering Playbook principles and the on-call overview
- [ ] Join the team channels and the incident channel

## First week

- [ ] First pull request merged (target: 5 working days or less) Date: ______
- [ ] Watched or took part in one code review with the buddy
- [ ] Watched one deployment to production
- [ ] Completed required security and privacy training. Date: ______
- [ ] Read the code assistant policy and got access to approved tools
- [ ] Assured: policy acknowledgements recorded

## First 30 days

- [ ] At least 3 changes shipped to production. First production change date: ______
- [ ] Read the team's ADRs and the architecture overview
- [ ] Reviewed pull requests as a second reviewer
- [ ] Fixed at least one thing in the onboarding docs
- [ ] 30-day check-in with manager, goals for day 60 written down
- [ ] 30-day onboarding survey completed

## First 60 days

- [ ] Owned a small feature from design to production
- [ ] Reviewing pull requests as a primary reviewer
- [ ] Shadowed one on-call rotation (if the team runs on-call)
- [ ] 60-day check-in, goals for day 90 written down

## First 90 days

- [ ] Working independently on normal tasks
- [ ] Primary on-call shift taken, after at least 1 shadow rotation (if applicable)
- [ ] Gave written feedback on onboarding to the manager
- [ ] 90-day onboarding survey completed
- [ ] Assured: access review done, holding only what the role needs. Reviewer: ______ Date: ______
